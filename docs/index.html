Modules

commands.check check 命令：检查指定插件的元数据与文件完整性 修正：io.read → io.open；marker 名与 plugin.lua 统一。
commands.notice notice 命令：查看官方公告
commands.plugins 插件市场命令：install / search / update / list
commands.remove remove 命令：彻底删除一个插件
commands.update update 命令：更新 YYfloat 自身 关键顺序：先备份旧版本 → 再切换软链接（原实现顺序相反，会备份到新版本）。
commands.use use 命令：查看插件文档/版本/作者/许可证，或启动插件
config YYfloat 全局配置模块 集中定义路径、常量与远端地址，避免魔术字符串散落各处。
core YYfloat 底层工具模块 提供文件复制/软链接、HTTP 请求、JSON 读写、路径与名称校验等基础能力。
plugin YYfloat 插件模块 负责插件存在性检查、搜索、启动脚本执行。 元数据采用惰性加载：每次调用都重新读取 PLUGINS_LIST， 避免模块加载期读文件导致"首次运行崩溃"与"元数据过期(stale)"问题。
