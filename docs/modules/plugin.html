Module plugin

YYfloat 插件模块 负责插件存在性检查、搜索、启动脚本执行。 元数据采用惰性加载：每次调用都重新读取 PLUGINS_LIST， 避免模块加载期读文件导致"首次运行崩溃"与"元数据过期(stale)"问题。
