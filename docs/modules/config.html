Module config

YYfloat 全局配置模块 集中定义路径、常量与远端地址，避免魔术字符串散落各处。

Tables

Config.REQUIRED_FILES 插件必需文件清单（相对插件目录）

Fields

Config.VERSION 当前 YYfloat 版本号
Config.HOME 用户主目录
Config.ROOT YYfloat 数据根目录
Config.DIST_DIR 分发二进制存放目录
Config.BACKUPS_DIR 备份目录
Config.PLUGINS_DIR 插件安装目录
Config.SELF 可执行文件名称
Config.SYSTEM 当前平台标识（用于选择远端清单）
Config.PLUGINS_LIST 插件元数据清单文件
Config.VERSION_FILE 本地版本记录文件
Config.MARKER_FILE 插件目录内的归属标记文件 用于区分"YYfloat 管理的插件目录"与"被外部占用的同名目录"。
Config.MANIFEST_URL 远端清单地址
Config.PLUGINS_URL 远端插件表地址
Config.NOTICE_URL 公告接口地址
Config.HTTP_TIMEOUT 网络请求默认超时（秒）
Config.DOWNLOAD_RETRY 下载重试次数
Config.PLUGIN_NAME_PATTERN 插件名称合法字符
